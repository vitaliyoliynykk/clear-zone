## 🚀 **How to Run the Project**

This project uses [pnpm](https://pnpm.io/) – install it first.

### 📌 **Steps**

1️⃣ **Ensure Node.js version is correct**

```sh
nvm use
```

2️⃣ **Start the development server**

```sh
pnpm run dev
```

🎉 **Your Pomodoro timer is now running!**
